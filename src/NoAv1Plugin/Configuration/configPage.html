Rules apply a restricted device profile to matching sessions, so Jellyfin never offers (or transcodes to) codecs those devices can't actually handle. Pick a previously-connected device to see which codecs it has actually reported supporting — unsupported codecs are greyed out and unchecked automatically, but you can still uncheck a codec the device claims to support if it's known to be broken in practice.
